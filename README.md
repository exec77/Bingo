# Bingo

Bingo помогает Codex довести поручение до результата, который запросил пользователь. После ответа субагента, смены контекста или неудачной проверки агент возвращается к исходной цели и выполняет следующий необходимый шаг.

Например, если человек попросил сравнить варианты перед принятием решения, работа заканчивается пригодным для выбора сравнением. Если он поручил осуществить выбранный вариант, агент проверяет результат в тех условиях, в которых человек будет им пользоваться.

## Установка в Codex

Из корня клонированного репозитория выполни:

```sh
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills/bingo"
cp bingo/SKILL.md "${CODEX_HOME:-$HOME/.codex}/skills/bingo/SKILL.md"
```

Чтобы включить Bingo по умолчанию, добавь в пользовательский файл `~/.codex/AGENTS.md` следующий абзац. Если задан `CODEX_HOME`, используй соответствующий каталог в путях к обоим файлам.

> Применяй Bingo к каждой задаче и её продолжению. Перед первой задачей прочитай `~/.codex/skills/bingo/SKILL.md` и следуй ему вместе с профильными скиллами. Отдельное сообщение `bingo` без учёта регистра вызывает скилл явно. Восстанови цель текущей задачи и продолжай с ближайшего незавершённого шага.

В новом чате скилл можно вызвать и напрямую командой `$bingo`.
